# 게임 내 등록 및 전투 효과 구현 현황 (v0.2.0 소스)

## 확인된 모딩 접점

다음 오픈소스 커스텀 아이템 모드의 패턴을 검토한 뒤, 동일한 게임 접점에 대한 독립적인 최소 구현을 추가했습니다.

- https://github.com/MrBacanudo/SkulHardModeMods/tree/main/CustomItems
- https://github.com/damku1214/VoiceOfTheCommunity

`CustomItemRegistration.cs`:
- 게임 `GearResource.Initialize` 시 해금 아이템을 아이템 목록에 주입 (다음 실행부터)
- 비동기 아이템 요청 추적 및 드롭되는 아이템의 런타임 프리팹 교체
- 아이템 이름/설명 로컬라이징
- 아이템 등급/각인 등록, 일부 기본 스탯 적용

**주의:** 이는 게임 호출 지점을 실제로 대상으로 하는 실험 코드이지만 현재 환경에서 게임 DLL이 없고 C# 컴파일러도 없어 **컴파일/실행 검증 전**입니다. 게임에서 사용 가능한 완성본이라고 판단하지 마세요.

## 게임 등록 12종

은빛 모피, 야생의 표식, 거인의 식칼, 살점 핵, 만능 플라스크, 완벽한 마석, 험악한 가면, 파괴자의 검, 세 번째 눈, 쇠사슬, 루비 심장, 왕가의 휘장.

## 적용 구현 vs 미적용

- 적용을 시도한 패시브: 은빛 모피 이동속도 +40%, 야생의 표식 이동속도 +90%, 살점 핵 최대 체력 +100, 험악한 가면 교대 쿨다운 +20%, 세 번째 눈 마법공격력 +50%
- **나머지 이벤트 효과는 미구현.** 등록 및 설명만 들어 있으며 효과는 발동하지 않음: 무적 쿨다운, 이동속도 비례 공격력, 회복 트리거, 피해 감소/부활, 랜덤 상태이상, 교대 둔화, 스킬 시전 중 버프, 자동 눈 공격/기절, 쇠사슬, 출혈 및 회복, 추가 출혈 공격
- 완벽한 마석 효과는 업로드된 스크린샷에 텍스트가 없으므로 그대로 미정
- 기존 프로젝트의 보스 처치 후 자동 해금 훅도 아직 연결되지 않음
- 아이콘은 라이선스 문제로 포함하지 않으며 기본 아이콘을 임시 활용
