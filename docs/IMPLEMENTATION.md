# 실제 게임 연동 체크리스트

현재 빌드는 **스켈레톤**입니다. 런타임 훅을 검증하기 전에는 아이템을 만든 것으로 간주하지 마세요.

1. 사용 중인 Skul 버전, BepInEx 5 버전, Unity 관리 어셈블리를 확인한다.
2. 영원의 웨어울프/구우우우울/검은 연금술사/디스트로이어/아크리치/친위대장의 실제 게임 내부 식별자를 찾는다.
3. 알렉산더 패배 이벤트와 처치 시점 스컬 판정을 Harmony 패치로 연동한다. 이중 호출 및 일반/다크 미러 구분을 테스트한다.
4. `OnVerifiedAlexanderKill` 호출을 연결하고 영속 저장 파일의 정상 복구를 확인한다.
5. 아이템 아이콘 제작 또는 사용 허락된 리소스를 확보한다. 원본 스크린샷은 권리 확인 없이 그대로 패키징하지 않는다.
6. 12개 아이템의 등록, 각인, 드롭 테이블, 상점 등장, 획득/제거, 중복 효과를 실제 게임 API로 구현한다.
7. 타이머/쿨다운/교대/피격/치명타/상태이상/부활/출혈의 반복 적용과 스테이지 전환 시 정리를 테스트한다.
8. 원문에 없는 세부 수치: 완벽한 마석 효과, 파괴자의 검 상승 속도, 세 번째 눈 데미지와 기절 시간, 쇠사슬 피해 공식 등을 작성자에게 확인한다.
9. 테스트용 DLL과 정상 동작 영상 확보 후 GitHub Release 또는 Thunderstore로 배포한다.
